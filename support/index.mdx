## Symptom-Matrix

Wenn der Kunde über **dieses Problem** schreibt → direkt zu dieser Seite:

| Symptom (was der Kunde schreibt) | Wo nachschauen |
|---|---|
| „Ergebnis falsch" / „falscher Torschütze" / „falsches Endergebnis" | [Datenfehler-Bugs](/support/bugs/live-daten) · Kunden-Seite |
| „Ticker läuft nicht ein" / „keine Liveticker-Einträge" | [Runbook: Liveticker läuft nicht ein](/support/runbooks/liveticker-einlauf) |
| „Ergebnis fehlt" / „Endstand kommt nicht an" | [Runbook: Fehlende Ergebnisse](/support/runbooks/fehlende-ergebnisse) |
| „Feed leer" / „XML-Feed ohne Daten" | [ntv.de-Profil](/support/kunden/ntv) · [Live-Daten Bugs](/support/bugs/live-daten) |
| „DSV-ID fehlt" / Sophora-Fehlermeldung | [MDR-Profil](/support/kunden/mdr) · [Live-Daten Bugs](/support/bugs/live-daten) |
| „Stream fehlt im Livecenter" / „Netcast nicht sichtbar" | [NDR-Profil](/support/kunden/ndr) · [Live-Daten Bugs](/support/bugs/live-daten) |
| „Widget leer" / „Highlight-Widget zeigt nichts" | [Widgets & UI Bugs](/support/bugs/widgets-ui) |
| „Darstellung falsch" / „Layout kaputt" / „Logo fehlt" | [Widgets & UI Bugs](/support/bugs/widgets-ui) |
| „Aufstellung fehlt" / „Kader nicht aktuell" | [Live-Daten Bugs](/support/bugs/live-daten) · Kunden-Seite |
| „Sprungmarke funktioniert nicht" / „Navigation fehlt" | [ZDF-Profil](/support/kunden/zdf) · [Widgets & UI Bugs](/support/bugs/widgets-ui) |
| „Leere Meldungen" / „Ticker-Text leer" | [dpa.com-Profil](/support/kunden/dpa) · [Live-Daten Bugs](/support/bugs/live-daten) |
| „Print-Tabelle fehlt" / „PDF-Export kaputt" | [Print Bugs](/support/bugs/print) |
| Infrastruktur / Server / Job hängt | [Infrastruktur Bugs](/support/bugs/infrastruktur) |
| Elfmeterschießen-Fehler / KO-Spiel-Daten falsch | [Live-Daten Bugs](/support/bugs/live-daten#wm-elfmeterschiessen--doppelter-eintrag--falscher-status) |
