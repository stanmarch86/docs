## Feed-URLs

| Feed | URL |
|---|---|
| Match (einzeln) | `https://dpa-msu.json.c.ergebnis-dienst.de/match/ma{match_id}/` |
| Match (Season-Kontext) | `https://dpa-msu.json.c.ergebnis-dienst.de/match/se{season_id}/ro{round_id}/ma{match_id}` |

<Note>
  Wenn der Match-Feed leer ist, aber der Season-Feed eine Response liefert: das ist ein Hinweis auf ein Datenproblem (z. B. fehlendes `match_date_end`), nicht auf ein Feed-Problem. Siehe [Runbook: Ergebnisse fehlen](/support/runbooks/fehlende-ergebnisse).
</Note>

## Wettbewerbe

### GFL — German Football League (American Football)

- Website: https://gfl.info/
- Unterteilung in **zwei Gruppen: Nord und Süd**, jeweils eigene Tabelle
- Spielergebnisse laufen über den DSV-Import / SportDB

---

## Bekannte Eigenheiten

- Zwischenergebnisse (Halbzeit etc.) können im Admin vorhanden sein, während das **Endergebnis fehlt** — Ursache ist meist ein fehlendes `match_date_end` in der SportDB (kein DSV-Import-Fehler)
- Manuelles Nachtragen im Admin bringt keine Besserung wenn das Problem in der SportDB liegt
